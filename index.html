Import from OneNote

  1. Set up
  2. Sign in
  3. Import

Once only, about 5 minutes. Microsoft only lets apps it knows read OneNote, so you register Inkwell with Microsoft and copy back one ID. Easiest on a computer: open Inkwell there, do the whole import there, and it syncs to the iPad.

  1. Open Microsoft Entra and sign in with the Microsoft account that has your OneNote.
    Open Microsoft Entra
    If it says you have no access or no directory: first make a free Azure account (it asks for a card to check it is you; registering Inkwell costs nothing), then open Entra again.
    Free Azure account
  2. New registration. Type App registrations in the search bar at the top, open it, tap New registration.
  3. Fill in the form. Name: Inkwell Supported account types: Accounts in any organizational directory and personal Microsoft accounts Redirect URI: choose Single-page application (SPA), then paste Tap Register.
  4. Copy the ID. On the page that opens, copy Application (client) ID and paste it here.

No redirect field in the form? Add it after registering: Authentication → Add a platform → Single-page application.

Set up is done. Now sign in with the Microsoft account that has your OneNote notebooks and allow Inkwell to read them. Inkwell only reads; nothing in OneNote changes. After signing in you come back here and pick what to bring over.

Each OneNote notebook becomes a notebook here, with its sections and pages: typed text, pictures and handwriting. Pages that were imported before are skipped, so you can run this again later.

Keep Inkwell open and in front until it finishes. If it stops, run the import again: it continues where it left off.
